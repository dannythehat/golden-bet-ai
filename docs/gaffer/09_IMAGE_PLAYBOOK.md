# 09 — Image Playbook

**Status:** Permanent · how the Gaffer's world looks.

Images carry the same character as the words: premium, witty, football-mad,
unmistakably Footy Oracle. This doc briefs the look so any image generated for
the Gaffer feels like it belongs.

## The look

- **Palette:** deep purple (#130321 / #07000f) + gold (#f5c542). Club colours.
- **Mood:** floodlit, cinematic, a bit theatrical — matchnight, not a stock photo.
- **The Gaffer:** the same character throughout — a fun, human, witty manager
  type (not a stiff suit). Pointing, grinning, mid-banter, tactics board behind.
- **Branding:** the Footy Oracle crest (purple ball + gold crown) where it fits;
  "THE GAFFER KNOWS" tone.

## Recurring subjects

- The Gaffer himself (hero shots, reactions, "Trust the Gaffer" neon).
- The Donkey mascot (sunglasses, cheeky) — for Donkey of the Week.
- Trophies, prize imagery (holiday, hampers, signed shirts) — premium, aspirational.
- Stadium / crowd / floodlights for atmosphere.

## Brief format (what to hand the image tool)

```
Subject: <who/what>
Action/mood: <pointing, grinning, lifting a trophy…>
Setting: floodlit stadium / clubhouse / tactics board
Palette: deep purple + gold, cinematic night lighting
Branding: Footy Oracle crest / "The Gaffer" hoodie (subtle)
Aspect: <hero 16:9 / square / portrait>
Avoid: stock-photo blandness, corporate vibe, real club logos/players
```

## Hard rules

- **No real club badges or real player likenesses** in generated art (rights).
  Real club *crests* only appear as live data on the form tables / tips (small,
  factual), not in marketing artwork.
- **Consistent Gaffer.** Same character, recognisable across every image.
- **On-brand colour** every time — purple + gold, never off-palette.
- **Premium, never naff.** If it looks like clip-art, it doesn't ship.
- **Approved assets** are the source of truth on the homepage (Lovable's
  `HOMEPAGE_APPROVED_ASSETS`); briefs here feed new approved assets, they don't
  override the locked ones.

## Ownership

The Gaffer Engine writes the image *briefs* in his world; the owner/Lovable
generate, approve and wire the actual assets. Claude supplies any data that an
image needs to be accurate (e.g. the fixture for a match-graphic), never the art.
